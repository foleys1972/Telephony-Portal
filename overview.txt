Telephony DDI Management Portal - Complete System Overview
🎯 System Purpose
A comprehensive web-based management system for telecommunications infrastructure including:

DDI (Direct Dial-In) Numbers - Phone number allocation and tracking
Private Wires - Dedicated communication lines management
Dealerboard Turrets - Trading floor equipment tracking
Turret Moves - Equipment relocation planning and tracking
User Management - Role-based access control
CSV Import/Export - Bulk data operations with field mapping

🔄 Key Workflows
1. DDI Number Management

Add DDI → Validate format → Store in database
Request Spare → Find oldest spare → Assign to user
Import DDI → Map CSV fields → Bulk import
Export Data → Generate CSV with all DDI records

2. Private Wire Tracking

Add Wire → Record technical details → Track assignments
Edit Details → Update user assignments and notes
Cease Wire → Move to ceased archive → Track reason

3. Turret Move Planning

Filter Turrets → Select multiple units → Plan move
Bulk Moves → Same destination with unique identifiers
Track Progress → Planned → In Progress → Completed

4. Import System

Upload CSV → Detect encoding → Show preview
Map Fields → Match CSV headers to database columns
Save Template → Reuse mappings for future imports
Process Data → Validate → Import → Report results
